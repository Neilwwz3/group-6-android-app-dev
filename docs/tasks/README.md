# 任务卡

每个任务一张卡。做任务前：

1. 先读仓库根目录的 `AGENTS.md`（项目规则）。
2. 再读自己的任务卡，看清“可以改”“不要改”和“验收标准”。
3. 用 AI 时，把 `AGENTS.md` 和任务卡一起交给 AI。Codex、Claude Code 会自动读取 `AGENTS.md`；网页版 AI 需要手动贴进对话。
4. 先切到 `dev` 并拉取最新代码，再按卡上的分支名新建分支。
5. 做完按 PR 模板向 `dev` 提 PR，在右侧 **Reviewers** 里选下表中你的审核人。
6. 审核人批准、自动编译显示绿色对勾之后，你自己点 **Merge pull request** 合并。
