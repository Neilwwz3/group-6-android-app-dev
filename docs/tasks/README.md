# 任务卡

每个任务一张卡。做任务前：

1. 先读仓库根目录的 `AGENTS.md`（项目规则）。
2. 再读自己的任务卡，看清“可以改”“不要改”和“验收标准”。
3. 用 AI 时，把 `AGENTS.md` 和任务卡一起交给 AI。Codex、Claude Code 会自动读取 `AGENTS.md`；网页版 AI 需要手动贴进对话。
4. 先切到 `dev` 并拉取最新代码，再按卡上的分支名新建分支。
5. 做完按 PR 模板向 `dev` 提 PR，在右侧 **Reviewers** 里选下表中你的审核人。
6. 审核人批准、自动编译显示绿色对勾之后，你自己点 **Merge pull request** 合并。

一个目标可以由两个人合作完成。拆分的时候想清楚彼此之间的接口：谁的页面打开谁的页面、传什么参数、谁做的组件给谁用。接口定了就不要随便改；要改，先在群里说，并通知用到它的人。

### 共同要求

1. **数据：** 只用 `docs/data-api.md` 里的方法，不要直接用 DAO，也不要自己建表。缺方法就找统筹。
2. **样式：** 只用视觉规范里的颜色、字号、间距和样式，布局里不写死色值。
3. **文字：** 界面上能看到的一切都用英文（包括数据里会显示的内容和日期格式），全部写进 `strings.xml`。详见 `AGENTS.md`“界面语言”一节。
4. **空状态：** 每个页面在没有数据时都要显示提示文字。
5. **PR：** 一个 PR 只做一件事，不要攒成一个大 PR。按上面的轮换表审核。
